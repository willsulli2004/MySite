# Portfolio site

Static site. To deploy on GitHub Pages:

1. Copy every file in this folder (including the hidden `.image-slots.state.json` and `.nojekyll`) into the root of your repo.
2. Commit and push to `main`.
3. GitHub → repo → Settings → Pages → Source: "Deploy from a branch", Branch: `main` / `/ (root)`. Save.
4. Site appears at https://willsulli2004.github.io/<repo-name>/ in about a minute. Name the repo `willsulli2004.github.io` to host at the bare URL.

Photos live in `.image-slots.state.json`. Re-export this folder whenever you change the site.
